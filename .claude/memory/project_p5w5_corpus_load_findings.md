P5W5 (prod cutover) corpus loads onto staging surfaced several non-obvious facts (owner 2026-06-16):

- **`source_corpus="lk"` = Sunni six-books (al-kutub al-sittah)**, NOT al-Kafi/Shia. al-Kafi lives under `source_corpus="thaqalayn"`, sect=shia. Don't conflate `lk` with Shia. lk is da#174's domain.

Real schema = `id`,`arabicText`,`englishText`,`majlisiGrading`/`behbudiGrading`/`mohseniGrading`, V2 `thaqalaynSanad`/`thaqalaynMatn`. Result: 0% matn_ar, 59 unique source_ids for 113k rows. Textbook [[project_p4 main#671 fixture-realism]] failure. Fix = real-field map + scope acquire to V2 dir (exclude allBooks*/BookNames/config) + real-upstream parse-path test + gate on `make validate` strict.
- **Thaqalayn upstream carries only al-Kafi + al-Faqih — NOT Tahdhib al-Ahkam or al-Istibsar.** So "Shia Four Books" is half-available from this source. Owner call: load al-Kafi+al-Faqih now (da#175) AND source the other 2 this wave → split into **da#182** (investigate-first; escalate if no clean source).
